# Piano Simulator

[English](README.md) | 繁體中文

用電腦鍵盤彈鋼琴。用 C 和 [raylib](https://www.raylib.com/) 從零開始寫，重點放在**手感**：按下按鍵到出聲的延遲要越低越好。

> 🚧 專案剛開始，還沒有可以執行的程式。進度和設計請看 [PLAN.zh-TW.md](PLAN.zh-TW.md)。

## 預計功能

- 🎹 用電腦鍵盤彈奏，播放真實鋼琴的錄音
- 🎶 可以同時按好幾個鍵彈和弦
- 🦶 空白鍵當延音踏板
- ✨ 畫出鋼琴鍵盤，按下時有動畫和特效
- 📖 教學模式：把 MIDI 檔拖進視窗，音符從上往下掉，提示該按哪個鍵

## 建置

> 還沒有程式碼，建置方式會在里程碑 1 完成後補上。

預計環境：

- Windows 11
- [raylib 官方 Windows 安裝包](https://raysan5.itch.io/raylib)（內附 w64devkit 編譯器）
